Problem: Search a list of names for one target name and report whether it was found.
Input:
- a list of names
- one target name
Output:
- "Found" or "Not found"
- or an error if the list is empty
Pseudocode:
START
IF list is empty THEN
    PRINT "Error: list is empty"
    STOP
ENDIF

SET found_status TO "Not found"
FOR EACH name IN list DO
    IF name == target name THEN
        SET found_status TO "Found"
    ENDIF
ENDFOR

PRINT found_status
END
