Problem: Search a list of names for one target name and report whether it was found.
Input:
- a list of names
- one target name
Output:
- "Found" or "Not found"
- or an error if the list is empty
Pseudocode:
START
  IF list is empty THEN
    PRINT "Error: list is empty"
  ELSE
    SET found = FALSE
    FOR each name IN list
      IF name == target THEN
        SET found = TRUE
        BREAK
      END IF
    END FOR
    IF found == TRUE THEN
      PRINT "Found"
    ELSE
      PRINT "Not found"
    END IF
  END IF
END
