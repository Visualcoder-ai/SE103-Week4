Problem:
Count how many numbers in a list are greater than 10.

Input:
a list of numbers: 4, 15, 10, 22, 8

Output:
the count, or an error if the list is empty

Pseudocode:
START
INPUT list of numbers 
INPUT Numbers greater than_10
IF list is empty THEN
	OUTPUT "Error: This List is empty.Enter an actual list"
ENDIF

SET count to 0
FOR EACH number IN list DO
	IF number > 10 THEN
		set count TO count + 1
	ENDIF
ENDFOR

PRINT count
END
